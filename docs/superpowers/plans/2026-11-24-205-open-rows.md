# Open every task and chore from its row Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: superpowers:executing-plans (CLAUDE.md PR flow step 3). Steps use checkbox (`- [ ]`) syntax for tracking.

**Issues:** [#205 Open every task and chore from its row](https://github.com/SlatinskyJ/taskmaster/issues/205), with [#195 Task page: a brother cannot reserve a free task from its own page](https://github.com/SlatinskyJ/taskmaster/issues/195). [#222 Open a Sporné item on Správa](https://github.com/SlatinskyJ/taskmaster/issues/222) is NOT in this PR: the admin may not open `/ukol`, `/sablona` or `/tyden` today (`src/lib/nav.ts` `SCREEN_ROLES`), so it needs its own decision and PR.

**Goal:** Tapping a row's name or body opens its page (`/ukol/$taskId` for a one-time task or a chore's copy, `/sablona/$templateId` for a recurring chore, proposed ones included); a copy's page links to its chore; a brother can reserve a free task from its page.

**Stacked on [#226 Approve done work from the task page and Úkoly](https://github.com/SlatinskyJ/taskmaster/pull/226):** the build starts once #226's code is on its branch; this PR's base becomes `206-approve-from-task-page` (GitHub stack), so `ApprovableRow` and `TaskWorkPanel` changes merge in one order. If #226 changes after that, this branch merges it in.

**Architecture:** One change in `TaskRow`: an optional `link` turns the name into a TanStack `Link` whose `::after` covers the whole card (stretched link); the row's action and footer sit above it (`relative z-10`), so buttons keep their own action. Each list passes `link` only when the new launch switch `openRows` is on. Server: `getTemplateDetail` stops hiding a proposed chore from brothers (they are parties who must agree to it, spec §5.1, and already see it on Domů). The task page gets Rezervovat + Hotovo for a brother on an open task, reusing `TakerBoard`'s calls.

**Tech Stack:** TanStack Start/Router (React, TS), Tailwind v4, vitest, Playwright, Drizzle (one data-only migration).

**Spec:** `docs/superpowers/specs/2026-11-16-taskmaster-design.md` §5.1 (template agreement by all parties), §5.4 (a taker reserves an open task, or marks it done without reserving). No rule change.

**Size:** about 300 changed lines outside tests: `TaskRow` ~25, ~12 call sites × ~5, task page + work panel ~50, template page ~40, server 3, switch + migration ~15, strings ~5. One PR: every part is the same row-tap pattern behind one switch.

## Global Constraints

- Czech UI text only in `src/lib/strings.ts`. New strings: `cs.tasks.chorePageLink: 'Otevřít opakovaný úkol'`, `cs.work.reserveHint`, `cs.templatePrice.proposed(score)`, `cs.templatePrice.startsWhenAll` (texts in Tasks 4–5). Rezervovat reuses `cs.work.reserve` (the `aria-label` of `TakerBoard`'s reserve button).
- Tap targets ≥ 44 px; the whole card is the tap target, the buttons stay ≥ 44 px.
- Focus: the stretched link is one focusable element per row with a visible focus ring on the card (`focus-visible:` on the link's `::after` outline). Buttons stay separate tab stops.
- Launch switch per `src/server/features/README.md` (`openRows`, off in prod, migration 0027 or next free number).
- `/ukol` and `/sablona` stay giver+taker screens; the admin gets no new access here.
- Rows without a page stay plain: Týden adjustments (#48), proposal rows (`/tyden/pristi` already has its button), Schůzka lists (not listed in #205).

## Review Focus

1. Tapping a button on a linked row (Hotovo, ↶ Uvolnit, Rezervovat, ✓/✕ from #206, Souhlasím, Otevřít, Rozporovat footer) runs the button, never navigates. Unit test asserts the action wrapper and footer are `relative z-10` siblings above the link; e2e taps Hotovo on a linked Domů row and stays on Domů.
2. A brother taps a proposed chore (Vynést koše, Návrh) on Domů: `/sablona` opens (today it is a 404 for him), shows Návrh, price, who agreed and his Souhlasím. Server test + e2e.
3. Switch off (prod today): no row has a link (test: switch off → no `<a>` around any row name). The server change in Task 4 is not behind the switch: the switch hides entry points only (features README), and a brother reaching a proposed chore's page by URL sees only what Domů already shows him.
4. A long Czech name (~30 letters) on a linked row at 360 px still wraps to two lines, the link does not change the row's height. Screenshots.
5. A brother opens a free task's page: Rezervovat and Hotovo; after Rezervovat the page shows Hotovo + Uvolnit (his reservation). A parent on a free task sees neither (spec §5.4 is the taker's). The other brother on a task reserved by his brother sees neither (existing `canWorkOn`).
