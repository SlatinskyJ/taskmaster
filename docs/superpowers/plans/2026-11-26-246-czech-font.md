# Czech letters in one font: Baloo 2 for words, Fredoka for numbers — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Issue:** [#246 Fix hard-to-read font and Czech letters](https://github.com/SlatinskyJ/taskmaster/issues/246)

**Goal:** Every Czech letter on every screen is drawn by one of the app's own fonts, never by a system fallback.

**Cause (checked):** Fredoka (`@fontsource-variable/fredoka` 5.3.0, every subset) has no glyph for `ě č ř ů ť ď ň Ě Č Ř Ů Ť Ď Ň`. Headings, buttons, tabs, card/sheet/dialog titles, toasts, avatars and `num` use Fredoka, so those letters come from a system font ("Hotovo bez bodů", "Odpovědět", "Příští týden"). `@fontsource-variable/baloo-2` 5.3.0 latin + latin-ext covers every Czech letter (checked with fontTools).

**Decision (Jakub, project thread 2026-11-26 10:28 Prague, after side-by-side screenshots):** option 2 = **Baloo 2** for everything Fredoka draws today except numbers; **Fredoka stays for numbers** (`num`). Nunito stays the body font.

**Architecture:** Font tokens only. `--font-display` points at Baloo 2; a new `--font-num` token keeps Fredoka for `num` with Baloo 2 as the next family, so a Czech letter inside a `num` element (e.g. "Celkem 108 · odečteno 100") falls back per letter to Baloo 2, not to a system font. No component changes besides one conflicting class.

**Tech Stack:** Tailwind v4 `@theme` tokens, fontsource variable fonts, Playwright + Chrome DevTools Protocol for the test.

**Spec:** `docs/superpowers/specs/2026-11-16-taskmaster-ui-design.md` §2.3 (type) and §3 (points line "in Fredoka"). §2.3 says "Fredoka for headings and all numbers"; Jakub's decision changes the headings half. That doc line is changed in a **separate docs PR** (not in this PR, CLAUDE.md "never fix the spec inside a PR"); this PR links it.

**Size:** about 10 changed lines of source (CSS tokens, one import, one class, package.json), plus one e2e spec (~70 lines), one suite row, the lockfile.

## Review Focus

3. Avatar initials with a caron (e.g. "Č") → Avatar uses `font-display`, so Baloo 2; covered by the scan when the demo has such a name, otherwise by the token change alone.
4. Dark theme: tokens are theme-independent → one dark screenshot in Task 3.
5. The login screen (before any session) uses `font-display` for "Taskmaster" and the button "Přihlásit" → the scan in Task 2 includes `/login`.

- [ ] **Step 1: Write the test**

`e2e/fonts.spec.ts`, comment on top: Czech letters must come from the app's fonts (#246). Helper `systemFallbacks(page): Promise<string[]>`:
- `const cdp = await page.context().newCDPSession(page)`, `DOM.enable`, `CSS.enable`, `DOM.getDocument({ depth: -1 })`;
- `DOM.querySelectorAll(root, 'body *')`; for each node, `DOM.describeNode` is not needed: first collect in the page (`page.evaluate`) the indexes of elements whose **own text nodes** match `/[ěščřžýáíéůúťďňĚŠČŘŽÝÁÍÉŮÚŤĎŇ]/` and are visible (`checkVisibility()`), mark each with `data-cz-check="<i>"`, then `DOM.querySelectorAll(root, '[data-cz-check]')`;
- for each node `CSS.getPlatformFontsForNode({ nodeId })`; collect `"<text, first 30 chars>: <familyName>"` for every font with `isCustomFont === false`.

Tests:
```ts
test('login: every Czech letter uses an app font', async ({ page }) => {
  await page.goto('/login')
  await page.evaluate(() => document.fonts.ready)
  expect(await systemFallbacks(page)).toEqual([])
})

for (const path of ['/', '/ukoly', '/tyden', '/schuzka', '/profil']) {
  test(`${path}: every Czech letter uses an app font`, async ({ page }) => {
    await passwordLogin(page, 'tata')
    await page.goto(path)
    await page.evaluate(() => document.fonts.ready)
    expect(await systemFallbacks(page)).toEqual([])
  })
}

test('headings use Baloo 2, numbers Fredoka', async ({ page }) => {
  await passwordLogin(page, 'tata')
  await page.goto('/ukoly')
  await page.evaluate(() => document.fonts.ready)
  expect(await fontsOf(page, 'h1')).toEqual([expect.stringMatching(/Baloo/)])
  expect(await fontsOf(page, 'main .num')).toContainEqual(expect.stringMatching(/Fredoka/))
})
```
`fontsOf(page, selector)` = family names from `CSS.getPlatformFontsForNode` of the first match.

Add the suite row in `e2e/suites.ts` after `keyboard-approve`, comment: `// Czech letters in the app's fonts (#246). Read-only.`
